# Flair International CRM V2

## Default Logins
Management: management / management2011
Accounts: accounts / accounts123

## Local Run
python app.py

## Railway Start Command
python app.py

## Main Features
- Management full access
- Accounts only payments access
- SQLite database on server
- Clients, Processing, Payments, Leads, Audit Logs
- Active/Inactive dropdown
- Processing status dropdown
- CSV export
- JSON backup
